# 🏆 Kaggle Competitions Portfolio

Este repositorio contiene las soluciones, pipelines y código fuente desarrollados para diversas competiciones de **Kaggle**. El objetivo es mantener un historial limpio, modular y reproducible de proyectos de Machine Learning, Deep Learning y Ciencia de Datos.

---

## 📁 Estructura del Repositorio

Cada competición se organiza de forma independiente dentro de su propia carpeta, siguiendo este estándar:

```text
Kaggle-Competitions/
│
├── 📂 [nombre-competicion]/      # Proyecto independiente
│   ├── 📂 notebooks/             # Análisis exploratorio (EDA), entrenamiento e inferencia
│   ├── 📂 src/                   # Módulos reutilizables (DataLoaders, modelos, métricas)
│   ├── 📂 submissions/           # Historial de entregas (.csv)
│   └── 📄 README.md              # Descripción específica de la competición y enfoque usado
│
├── 📄 .gitignore
└── 📄 README.md                  # Visión general del portafolio
